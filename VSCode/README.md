# STM32 LVGL demo

This demo shows how to use LVGL on a STM32F411 using a ST7735 based LCD display and KY040 rotary encoder.

## Hardware details

- [WeAct Studio STM32F411 blackpill development board](https://github.com/weactstudio/weactstudio.ministm32f4x1)
- WeAct Studio 1.8" TFT LCD ST7735
- HY040 rotary encoder
